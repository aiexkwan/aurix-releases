# AURIX

[English](README.md) | **繁體中文**

AURIX 是一款與 AI 編程代理（agent）協作的桌面應用程式。它把代理、工具與任務放在同一個視窗內。

本頁寫給 AURIX 的使用者。下載與版本說明請見 [Releases 頁面](../../releases)。

## AURIX 能做什麼

- **同時與多個代理工作。** 並排開啟 Claude Code、Codex 等代理的終端機。每個終端機旁的標籤會顯示代理正在工作、等候你，或已閒置。
- **在同一處回覆代理。** 代理提問或需要你批准時，畫面最上方會出現一張卡片，不論你正在使用哪個應用程式。你可選擇答案，或按「批准」或「拒絕」。
- **Assistant。** 可用文字或語音與 Assistant 對話。它能代你啟動與監看代理、執行排程工作，並記住你的個人資料。派工看板會列出需要你決定的事項、進行中的工作與剛完成的工作。
- **任務與審查。** 把任務交給代理，它會在獨立的工作資料夾內作業。合併前，可按你設定的檢查清單核對成果。任務看板與流程列會顯示每項任務的進度。
- **MCP 外掛。** 在同一頁安裝與管理 MCP 外掛，並選擇每個代理或 Assistant 可使用的工具。金鑰存放於祕密儲存區。
- **內建瀏覽器。** 在 AURIX 內瀏覽網頁，支援分頁、書籤、儲存密碼，以及手機與平板螢幕尺寸。代理可以使用它，你也可以在其中審閱代理做出的原型。
- **記憶。** 代理會記錄決策與經驗，並在開始新工作前查閱。
- **技能（Skills）。** 可匯入自己的技能，並從任何終端機的右鍵選單執行。
- **遠端存取。** 經由你自己的 Tailscale 網絡或 SSH，從另一部電腦控制 AURIX。每次連線都會以六位數配對碼，以及 Touch ID 或 Windows Hello 驗證。
- **用量檢視。** 查看你的方案或 API 預算已用多少。

## 系統需求

- **macOS：** macOS 14 Sonoma 或更新版本，Apple Silicon（M1 或更新）。
- **Windows：** 64 位元（x64）。

## 安裝

**macOS**

1. 從 [Releases 頁面](../../releases)下載 `.dmg` 檔案。
2. 開啟後，把 AURIX 拖入「應用程式」資料夾。
3. 從「應用程式」開啟 AURIX。

**Windows**

1. 從 [Releases 頁面](../../releases)下載 `.exe` 安裝檔。
2. 執行並按指示完成安裝。

Windows 安裝檔目前尚未簽署。Windows SmartScreen 可能顯示「Windows 已保護您的電腦」。若檔案是從本頁下載，請按「其他資訊」，再按「仍要執行」。

## 更新

AURIX 會檢查新版本。新版本就緒時，應用程式會顯示 **Restart to Update**。按下後，AURIX 會重新啟動並更新至新版本。

你也可以從 [Releases 頁面](../../releases)下載最新版本，直接覆蓋安裝。
